          print()

  How the new line works, read from the inside out:
  - n * n is the largest product in the table, from the bottom-right corner.
  - str(...) turns that number into text, so 16 becomes "16".
  - len(...) counts the characters, so len("16") is 2. That's how many digits
    the biggest number has.
  - + 1 adds one more space so neighbouring columns never touch.
